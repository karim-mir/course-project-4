# Сервис управления рассылками

Проект представляет собой веб-приложение на Django для создания, редактирования и управления рассылками и их получателями.

---

## Основные возможности

- Авторизация пользователей с разграничением ролей (например, менеджер и обычный пользователь).
- Создание, просмотр, редактирование и удаление рассылок (Mailing).
- Управление получателями рассылок (MailingRecipient).
- Запуск и отключение рассылок с контролем прав доступа.
- Просмотр статистики по получателям рассылок.
- Подтверждение удаления с формой подтверждения.
- Ограничение доступа к рассылкам в зависимости от роли пользователя и владельца.

---

## Структура проекта

- users/ — приложение для управления пользователями.
- mailings/ — приложение для управления рассылками и получателями.
- newsletters/ — приложение для новостных рассылок (используется модель Newsletter).
- Используются классические Django generic views (ListView, DetailView, CreateView, UpdateView, DeleteView) с миксинами для контроля доступа.

## Установка и запуск

1. Клонируйте репозиторий:
git clone https://github.com/karim-mir/course-project-4<pre&g

2. Создайте и активируйте виртуальное окружение:
python -m venv venv
venv\Scripts\activate<pre>

3. Установите зависимости:
pip install -r requirements.txt
4. Выполните миграции базы данных:
python manage.py migrate<pre>

5. Запустите сервер разработки:
python manage.py runserver
6. Откройте в браузере [http://localhost:8000/mailings/](http://localhost:8000/mailings/) для работы с рассылками.

---

## Использование

- Для создания рассылки нажмите кнопку "Добавить сообщение" (доступно только авторизованным пользователям).
- Для редактирования и удаления рассылок доступны соответствующие ссылки, если вы являетесь владельцем или менеджером.
- При удалении появляется страница с подтверждением.
- Запуск и отключение рассылок доступны в деталях рассылки при наличии прав.
- Просмотр статистики получателей доступен по отдельному URL.

---

## Особенности реализации

- Контроль доступа реализован через миксины MailingAccessMixin и MailingOwnerPermissionMixin.
- Используются декораторы @login_required и миксины LoginRequiredMixin для защиты представлений.
- Контекст шаблонов включает объект request и user для управления отображением элементов интерфейса.
- Шаблоны наследуются от базового users/home.html с единым блоком base_content для контента.
